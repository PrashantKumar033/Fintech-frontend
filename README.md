# UMOBIPAY Web Application

Frontend application for the UMOBIPAY payments platform, built with React, TanStack Start, Vite and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

The development server runs on port `8080`. Configure the API Gateway with `VITE_API_URL` when it is not available on port `8000` of the same host.

## Verification

```bash
npx tsc --noEmit
npm run lint
npm run build
```
